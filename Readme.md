# 🎓 Student Clubs Website

A modern, responsive web application designed to help university students discover, explore, and join campus clubs and upcoming events.

---

## 🌟 Features

- **🏠 Home Page (`index.html`):** Displays featured campus clubs, upcoming activities, and the platform mission statement.
- **🔍 Clubs Directory (`clubs.html`):** Browse all student organizations with interactive category filtering (Sports, Cooking, Music, Yoga) and search functionality.
- **📅 Events Hub (`events.html`):** View details on upcoming campus events including dates, times, locations, and hosting clubs.
- **📝 Join Club Form (`join-club.html`):** Seamless membership application form with input fields for student details and statement of interest.
- **ℹ️ About Page (`about.html`):** Background story and goals of the Student Clubs platform.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **Tailwind CSS:** Utility-first CSS framework for responsive layout and styling.
- **Google Fonts:** Inter & Poppins typography.
